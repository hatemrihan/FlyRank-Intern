# FlyRank

FlyRank is a capstone project repository for building an AI-assisted ranking experience.

## Project goal

This repository will hold the initial scaffolding for the FlyRank capstone work, including project conventions, documentation, and future implementation files.

## Quick start

1. Clone the repository.
2. Open the project folder in your editor.
3. Start adding your application code and documentation.

## Current focus

- Establish a clear capstone repository structure.
- Document the project conventions for future development.
- Keep the README easy for reviewers to scan quickly.

## Repository structure

- Main/ is reserved for the main application code and future implementation files.
- CLAUDE.md captures the stack and workflow conventions.
- LICENSE and .gitignore cover licensing and local development hygiene.

## Notes

- The repository uses Conventional Commits for commit messages.
- Keep documentation updated as the project grows.
- A short CLAUDE file is included to describe the stack and working conventions.
